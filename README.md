# 鹿音盒

一款专注于本地与在线音频播放的 Android 播放器。

## 版本

**v2.0.01** · 2026-09

## 功能概览

- 本地音乐 / 有声书 / 视频文件扫描、分类与管理
- 在线歌曲搜索、歌单浏览与播放
- 有声书在线书源浏览、章节播放、离线下载
- MV / 在线视频搜索与播放
- 专业音效调节系统(均衡器、重低音、3D 环绕等)
- 逐字高亮卡拉 OK 歌词
- 局域网 SMB / WebDAV / FTP 资源访问
- DJ 电音混音预设
- 桌面悬浮窗歌词
- 深色 / 浅色主题切换
- 播放记录、收藏、定时关闭、桌面小组件
- 自动下载歌词与封面

## 快速上手

1. 安装 APK 后,首次启动请授予「存储访问」权限,以便扫描本地音乐文件。
2. 若需访问在线资源或下载有声书,请保持网络畅通。
3. 「设置 → 关于」可查看详细的权限说明、隐私政策和免责声明。

## 安装与升级

APK 提供在本仓库的 Releases 页面。建议升级前先备份播放记录和收藏数据。

## 系统要求

- Android 8.0 及以上
- 至少 2GB 可用存储空间

## 安全与隐私

本软件不收集、不上传任何个人数据。所有播放记录、收藏、下载文件均存储在本地设备。在线搜索和播放仅代理传输公开可访问的网络资源,不做存储或再分发。

详见应用内「设置 → 关于 → 隐私政策」。
