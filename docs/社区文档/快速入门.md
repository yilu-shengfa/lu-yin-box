# 快速入门

## 第一步:安装

从本仓库 Releases 页面下载最新版 APK,在 Android 设备上安装。首次安装若出现安全提示,请允许安装未知来源应用。

## 第二步:授权

首次启动时,应用会请求以下权限,请全部允许:

| 权限 | 用途 |
|------|------|
| 存储访问 | 扫描和播放本地音乐、有声书、视频文件 |
| 媒体读取(Android 13+) | 读取手机中的音频和视频文件 |
| 网络访问 | 在线搜索、获取歌词封面、下载有声书 |
| 悬浮窗 | 桌面歌词小窗显示 |
| 通知 | 下载进度与播放状态提醒 |
| 电池优化白名单 | 保证后台稳定播放与下载 |
| 相机 | DJ 电音闪光灯功能(仅控制闪光灯,不拍摄照片) |
| 震动控制 | 播放/下载时的反馈震动 |
| 安装未知应用 | 便捷升级安装 |

## 第三步:扫描本地

进入首页后点击「本地音乐」或「有声书」,应用会自动扫描设备中的音频/视频文件。扫描过程中请保持应用在前台。

## 第四步:在线内容

「在线音乐」「有声书」「视频 MV」三大分类提供搜索和浏览功能。若某个源暂时不可用,请切换到其他源。

## 第五步:下载与离线

有声书支持离线下载:进入书籍详情 → 点击章节 → 选择下载全部或指定章节。下载进度可在「下载管理」中查看和重试。

## 常见问题

**Q:扫描不到音乐文件?**
A:检查存储权限是否授予、文件是否在系统扫描目录下(/Download、/Music、/Podcasts 等)。

**Q:有声书下载失败?**
A:保持网络畅通,切换内容源,或在下载管理中重试。

**Q:在线内容加载慢?**
A:切换到速度更快的内容源,或稍后再试。

**Q:歌词/封面不对?**
A:长按歌曲,选择「重新获取歌词/封面」。
